## Overview

- Package: `@the-docs/plugin-mermaid`.
- Factory: `mermaidPlugin()`.
- Target: code fences labelled `mermaid`.
- Render diagrams at build time as SVG-backed images.
- Separate from Ontology, which renders interactive inline Mermaid SVG.

## Ontology

- Extends [Plugin Contract](/p/plugin-contract).
- Appears in [Ontology preview](/p/plugin-ontology) through the shared contract.
