## Full workflow

- Mock data only. Not a production process specification.
- 14 document nodes. 18 declared relations.
- Asset is the subject, matching the thicker box in the reference chart.
- Eight hops include the whole connected example. Extension filter excludes unrelated site documents.
- Hover nodes for document descriptions. Hover relations for execution notes.
- Mermaid chooses layout. Reference positions and AL badges are not reproduced.
- Unlabelled arrows use `relates-to`; their business meaning is unspecified.
- Manual, automatic, and conditional notes stay in relation descriptions.
