## Document Structures

```
docs/
├── _types/
│   ├── dr/
│   │   └── type.json
│   └── doc/
│       └── type.json
├── _scopes/
│   └── engineering/
│       └── scope.json
├── _tags/
│   ├── docs/
│   │   ├── tag.json
│   │   ├── ui-ux/tag.json
│   │   ├── architecture/tag.json
│   │   └── specs/tag.json
│   └── feature/
│       ├── tag.json
│       ├── scope/tag.json
│       ├── tags/tag.json
│       ├── types/tag.json
│       ├── plugin/tag.json
│       └── search/tag.json
├── post-001/
│   ├── index.mdx
│   ├── index.th.mdx
│   └── assets/
│       ├── drawing-001.excalidraw
│       └── process-001.bpmn
└── post-002/
    ├── index.mdx
    └── index.th.mdx
```

## Documents

- Documents using flat structure (document directories must be exactly one level below)
- Use frontmatter for metadata
  - title: string
  - description: string
  - tags: string[]
  - type: `dr` | `doc`
  - priority: number (higher values appear first among related documents)
  - related-docs: string[] (document slugs; relationships are resolved both ways)
  - modified: date (optional; otherwise the file modification time is used)
- Support plugin like excalidraw, bpmn
- Assets stored within documents

## Tags

- Tags can be nested
- Nested tags use their full slash-delimited slug in frontmatter, such as `docs/ui-ux` or `feature/plugin`

Interface:

```typescript
interface TagDefinition {
  title: string
  description: string
  color?: string
}
```

## Scopes

Scopes are flat directories under `_scopes`. Each `scope.json` defines an ordered hierarchy of sections, groups, and document references. A group may provide a `document` reference, making the group heading itself a document link while retaining child documents. Optional `icon` fields use kebab-case Lucide icon names.

Documents opened through a scope use `/p/<document-slug>?scope=<scope-slug>` so scope navigation remains selected.

## Types

- Types won't be nested
- Supported types are `dr` and `doc`

Interface:

```typescript
interface TypeDefinition {
  title: string
  description: string
  color?: string
  // Related documents of this type render in their own collapsed section.
  "separate-related-docs-section"?: boolean
}
```
